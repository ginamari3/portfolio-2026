Aether Airlines is a conceptual airline brand built to communicate calm, clarity, and premium intention across digital + physical touchpoints.

The Challenge The Solution My Approach

The Challenge

Travelers are overloaded by noisy, stressful experiences. The challenge was to design a brand system that feels premium but not cold—calm, intentional, and easy to recognize across touchpoints.

  • Create a modern airline identity with warmth + clarity
  • Build a flexible visual system for web + packaging
  • Communicate “elevated travel” without being sterile

The Solution

Aether’s system combines a minimal mark, deep blues, and star-like accents to create a calm premium tone. The result is a consistent brand language that works from ticketing screens to packaging.

My Approach

Built around a “calm clarity” North Star—modern, premium, and warm.

01 — Research + Inspiration

Benchmarked premium travel brands and identified “calm clarity” as the North Star.

02 — Visual Direction

Defined moodboards, type direction, and icon/star motif to support the concept.

03 — System + Mockups

Built a cohesive set of colors, type rules, and applications across print + digital.

In Conclusion

This project strengthened my ability to design a consistent brand system and apply it across touchpoints. Next, I’d expand the UI into a full booking flow and refine the packaging suite for additional product lines.
